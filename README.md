# Day 05 — Linear Algebra: Vectors & NumPy

## 📌 Overview

Learned the fundamentals of **vectors** and implemented vector operations using **NumPy**, building the mathematical foundation required for Machine Learning.

## 🧠 Concepts Covered

* Scalar vs Vector
* Vector components and dimensions
* Vector representation
* Vector addition
* Vector subtraction
* Scalar multiplication
* Vector magnitude
* Element-wise operations
* Creating vectors using `np.array()`
* Vectorized computation with NumPy

## 💻 Implementation

```python
import numpy as np

X = np.array([5, 10, 15])
Y = np.array([2, 4, 6])

print("Vector X:", X)
print("Vector Y:", Y)

print("Addition:", X + Y)
print("Subtraction:", X - Y)
print("Multiplication:", X * Y)
```

## 🤖 ML Relevance

Vectors are used to represent **features and data points** in Machine Learning and form the foundation for:

* Distance calculations
* Similarity
* Clustering
* Regression & Classification
* Neural Networks
* Embeddings
